Evidence Tracker Project Artifacts

Project Overview

The Evidence Tracker application was originally developed during CS 360: Mobile Architecture and Programming and enhanced throughout CS 499: Computer Science Capstone. The project evolved from a basic inventory management application into a professional evidence management system through enhancements in software engineering, algorithms and data structures, and database design.

This page provides access to the original project artifact and each enhanced version completed during the capstone. Together these artifacts demonstrate the progression of the application while showcasing the technical knowledge and software development skills acquired throughout the Computer Science program.

Original Artifact

The original Evidence Tracker application was created during CS 360: Mobile Architecture and Programming. It established the foundation for the capstone by providing user authentication, SQLite database support, and basic CRUD functionality that was later expanded throughout the enhancement process.

Enhancement Progression

Enhancement One – Software Design & Engineering

Improved the application's architecture through secure authentication, administrator approval workflows, role-based access control, and a more maintainable software design.

Enhancement Two – Algorithms & Data Structures

Added efficient search, filtering, sorting, and improved data processing to enhance evidence retrieval and overall application usability.

Enhancement Three – Databases

Redesigned the SQLite database by implementing historical audit logging, improved data integrity, and enhanced evidence tracking capabilities.
