CS 499 Computer Science Capstone

Professional Self-Assessment

Albert White

Bachelor of Science in Computer Science
Southern New Hampshire University

When I began the Bachelor of Science in Computer Science program at Southern New Hampshire University, my understanding of software development centered primarily on learning how to write code. As I progressed through the curriculum, I discovered that computer science encompasses far more than programming alone. The program introduced me to software engineering, algorithms, database management, cybersecurity, operating systems, software architecture, artificial intelligence, reverse engineering, mobile application development, and full stack development. Each course expanded my technical knowledge while demonstrating how these disciplines work together to create reliable, secure, and maintainable software systems.

Developing this ePortfolio and completing the Computer Science Capstone provided the opportunity to reflect on that progression while demonstrating the knowledge and skills I developed throughout the program. As a Crime Scene Investigator, I often viewed assignments through the lens of real-world investigative work. This perspective influenced many of my projects and ultimately inspired the Evidence Tracker application featured in this portfolio. Rather than simply completing academic exercises, I sought opportunities to create software solutions that addressed practical problems while reinforcing the technical principles learned throughout the degree program.

Professional Growth Throughout the Program

Programming Foundations

My journey began with introductory programming courses, including Introduction to Scripting, Foundations in Application Development, and Programming Languages. These courses established the foundation for everything that followed by teaching variables, decision structures, loops, functions, object-oriented programming, and problem-solving techniques. More importantly, they introduced structured thinking and demonstrated how large problems can be divided into smaller, manageable tasks. These programming fundamentals became the basis for every subsequent course throughout the curriculum.

Software Engineering

As the program progressed, courses such as Software Development Lifecycle, System Analysis and Design, Software Testing, Automation, and Quality Assurance, and Full Stack Development shifted my perspective from simply writing code to engineering complete software solutions. I learned the importance of planning software before implementation, documenting requirements, communicating design decisions, performing iterative testing, and producing maintainable applications that continue to evolve after their initial release.

Database Development

Database development became one of the strongest areas of growth throughout my degree. Courses introduced relational database design, normalization, SQL, database connectivity, and data management principles. These concepts directly influenced the redesign of the Evidence Tracker database by improving data integrity, preserving permanent audit records, and maintaining historical evidence information while supporting efficient data retrieval.

Algorithms and Data Structures

Courses focused on Data Structures and Algorithms strengthened my ability to evaluate multiple approaches to solving complex computational problems. Rather than simply producing functional code, I learned to consider algorithm efficiency, scalability, and maintainability when selecting data structures and designing solutions. These concepts influenced the search and retrieval features implemented within the Evidence Tracker application.

Secure Software Development

Security remained a recurring theme throughout the curriculum. Coursework introduced vulnerability assessment, secure programming practices, authentication concepts, encryption, defensive coding, and secure software design. Applying these concepts during the capstone resulted in administrator approval workflows, secure login functionality, password management, and audit logging features that strengthen accountability while protecting sensitive evidence records.

Specialized Coursework

Additional coursework expanded my understanding of operating systems, software architecture, user interface design, mobile application development, artificial intelligence, reinforcement learning, and software reverse engineering. Collectively, these experiences reinforced the relationship between software design, hardware, security, usability, and performance while broadening my understanding of modern computer science.

Collaboration and Communication

Although many projects throughout the program were completed individually, collaboration remained an important component of my educational experience. Weekly discussion boards encouraged the exchange of ideas with classmates from diverse technical backgrounds, exposing me to alternative approaches for solving programming and design problems. Constructive feedback from peers and instructors challenged me to evaluate my own work critically while considering different perspectives on software development.

Technical Communication

Equally important was learning to communicate technical information effectively to multiple audiences. Courses in software engineering and system analysis emphasized documenting requirements, explaining design decisions, and presenting technical information in a manner that could be understood by both technical and nontechnical stakeholders.

Developing the capstone project further strengthened these skills through enhancement narratives, software documentation, testing reports, and presentations that clearly explained the purpose and implementation of each enhancement. These experiences reinforced that successful software development depends not only on technical expertise but also on the ability to communicate ideas clearly, collaborate effectively, and produce professional documentation throughout the software development lifecycle.

Preparing for a Career in Computer Science

Completing the Computer Science program significantly expanded my technical abilities while strengthening my confidence in approaching complex software projects. Throughout the curriculum, I developed experience with multiple programming languages, relational and nonrelational databases, mobile and web application development, software testing, secure coding practices, reverse engineering, artificial intelligence concepts, and modern software engineering methodologies. Each course built upon previous knowledge while introducing new technologies and development practices that prepared me for increasingly sophisticated software projects.

Applying Academic Knowledge to Real-World Problems

My professional experience as a Crime Scene Investigator influenced many of the technical decisions made throughout the capstone project. Designing software around real evidence management procedures required balancing technical functionality with practical usability, accountability, and security. This combination of professional experience and technical education allowed me to develop an application that reflects both academic achievement and practical problem solving.

The Evidence Tracker application represents the culmination of these experiences by integrating software engineering principles, algorithmic problem solving, database design, and secure development practices into a single project that addresses a real-world need. It demonstrates not only the technical knowledge acquired throughout the Computer Science program but also my ability to apply that knowledge to create practical software solutions.

Portfolio Overview

The artifacts presented throughout this ePortfolio demonstrate the progression of my technical knowledge while showcasing complementary areas of computer science. Each enhancement builds upon the original Evidence Tracker application by applying software engineering, algorithmic problem solving, and database design principles to create a more secure, maintainable, and capable software solution.

Code Review

The portfolio begins with a comprehensive code review of the original Evidence Tracker application. The review evaluates the strengths and limitations of the initial artifact while identifying opportunities for improvement that guided each enhancement completed throughout the capstone.

Software Design & Engineering

The first enhancement focuses on improving the architecture and maintainability of the Evidence Tracker application through administrator approval workflows, enhanced user management, improved navigation, secure authentication, and overall software organization. These enhancements demonstrate the application of software engineering principles, modular design, and user-centered development practices.

Algorithms & Data Structures

The second enhancement demonstrates improved evidence retrieval, search functionality, filtering capabilities, sorting, and more efficient data organization within the application. These enhancements reflect the application of algorithmic thinking and data organization principles to improve software performance, usability, and scalability.

Databases

The database enhancement redesigns the application's SQLite database by introducing permanent audit history, improved data integrity, historical evidence preservation, and stronger relationships between evidence and audit records. These improvements demonstrate the importance of well-designed database architecture in maintaining reliable, secure, and accountable software systems.

Evidence Tracker Project Artifacts

The final page provides access to the original artifact and each enhanced version of the Evidence Tracker application. Together, these artifacts document the evolution of the project from its original implementation through the completed capstone while demonstrating the technical growth achieved throughout the Computer Science program.

Reflection

Completing the Bachelor of Science in Computer Science program has provided me with a comprehensive understanding of software development while reinforcing the importance of continuous learning within the technology field. Looking back at the progression from introductory programming courses to the capstone project, I recognize not only how much my technical knowledge has expanded, but also how my approach to software development has matured. I now approach projects by considering software architecture, database design, security, testing, maintainability, user experience, and documentation before writing code.

The Evidence Tracker capstone project served as the culmination of this educational journey by integrating concepts from nearly every major course within the curriculum. Developing the application required applying software engineering principles, database design, secure coding practices, algorithmic problem solving, testing methodologies, and effective communication to create a practical solution for a real-world problem. This experience reinforced that successful software development extends beyond producing functional code and requires careful planning, thoughtful design, continuous testing, and collaboration throughout the development process.

As I complete this degree, I am confident that the knowledge, technical skills, and problem-solving abilities developed throughout the Computer Science program have prepared me to contribute effectively to software development projects while continuing to grow as a computing professional. This portfolio represents not only the culmination of my academic accomplishments, but also the foundation for continued professional development as I pursue future opportunities in computer science.
